# Cursor-reactive Glow + Magnetic Hover

Pointer-following glow with subtle magnetic feel.

## Usage

Import `Animation` and its stylesheet. Use in a client-rendered React tree. The sample is self-contained, accepts className and has no external asset requirements.

## Accessibility & performance

Native controls remain keyboard operable. Motion is disabled or reduced by `prefers-reduced-motion`; animations use CSS transforms/opacity where possible. Decorative elements are hidden from assistive technology. Test touch, keyboard focus, reduced motion, and narrow layouts.
